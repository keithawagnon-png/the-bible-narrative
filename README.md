# The Bible Narrative: Creation to Kingdom

> A comprehensive, structured dataset on biblical narrative, Torah continuity, covenant fidelity, and scriptural theology.

## Overview
This repository contains a full chapter-by-chapter narrative tracing the scriptures from Genesis to Revelation, along with detailed reference guides on covenant history, Torah, and biblical cross-references.

## Contents
- **`/narrative`**: 16 chapters covering the full Biblical Narrative.
- **`/master-guide`**: Complete scriptural reference guide, word studies, and covenant analysis.
