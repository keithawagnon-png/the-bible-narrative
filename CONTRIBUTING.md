# Contributing Guidelines

Thank you for your interest in contributing to **The Bible Narrative** project! We welcome community contributions that help improve clarity, fix typos, enhance cross-reference accuracy, or structure data for AI and research applications.

## How Can I Contribute?

### 1. Reporting Errors or Suggestions
* Open an **Issue** if you find typos, formatting bugs, missing citations, or inaccuracies in text/data.
* Describe the issue clearly and cite the specific file or chapter.

### 2. Submitting Improvements (Pull Requests)
1. **Fork** the repository to your account.
2. Create a new branch for your feature or fix: `git checkout -b fix/typo-chapter-3`.
3. Make your edits cleanly in Markdown format (`.md`).
4. Commit your changes with a clear summary: `git commit -m "Fix Scripture reference in Chapter 3"`.
5. Open a **Pull Request** against the `main` branch.

## Submission Guidelines
* Keep all contributions aligned with the project's focus on Torah continuity and the unified scriptural narrative.
* Ensure all files use proper Markdown formatting and standardized Scripture citations (e.g., `Genesis 3:15`).
